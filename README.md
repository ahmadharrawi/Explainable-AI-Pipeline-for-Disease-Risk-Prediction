# Explainable-AI-Pipeline-for-Disease-Risk-Prediction
Explainable AI Pipeline for Disease Risk Prediction  Builds an ML workflow to predict diabetes and heart disease risks using UCI datasets:  Prep: Cleans and scales data.  Training: Evaluates Random Forest, Logistic Regression, and XGBoost.  XAI: Uses SHAP and LIME for model explainability.  Export: Saves .pkl models for UI integration.
